# Steel Defect Detection

A computer vision based machine learning project for detecting and classifying defects in steel surface images.

---

## Problem Statement
In manufacturing industries, early detection of surface defects in steel sheets is critical to maintain quality and reduce losses.  
This project focuses on identifying defect patterns from image data using machine learning techniques.

---

## Approach
- Image preprocessing and feature extraction
- Model training using supervised learning techniques
- Evaluation using classification metrics

---

## Tech Stack
- Python
- Jupyter Notebook
- Machine Learning libraries (scikit-learn, etc.)

---

## Results
The trained model demonstrates effective classification performance on test data, showing the feasibility of ML-based automated inspection.

---
